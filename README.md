## فایل‌ها
- index.html — متن‌ها و ساختار بخش‌ها
- styles.css — قالب ریسپانسیو، رنگ‌ها و چیدمان
- script.js — عملکرد منوی موبایل، اسکرول و انیمیشن‌های سبک
- assets/logo.svg — نشان برداری برند بازطراحی‌شده بر اساس فایل ارسالی
- assets/og-cover.svg — تصویر اشتراک‌گذاری

این وب‌سایت عمداً **بخش نمونه‌کار** ندارد. تصویر معماری ابتدای سایت، تصویرسازی مفهومی است و تصویر پروژه اجراشده نیست.

## انتشار در GitHub Pages
در Settings → Pages، منبع را **Deploy from a branch**، شاخه را **main** و پوشه را **/(root)** قرار دهید. پس از انتشار و با یک بار به‌روزرسانی اجباری مرورگر، نسخه جدید در نشانی بالا نمایش داده می‌شود.

## تغییر محتوا
برای تغییر شماره تماس یا نام مدیریت از index.html استفاده کنید. برای تغییر پالت رنگ، متغیرهای ابتدای styles.css را ویرایش کنید. فایل‌ها بدون ابزار ساخت یا نصب پکیج مستقیماً در GitHub Pages اجرا می‌شوند.
